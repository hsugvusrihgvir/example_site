# Поволжский центр беспилотной авиации


- Основной сайт: https://ptsba.ru/

## Стек

- HTML
- CSS
- JavaScript

Сайт не требует сборки и серверной части.

## Структура

- `index.html` — главная страница
- `pages/` — внутренние страницы
- `assets/` — стили, скрипты и изображения
- `docs/` — документы для открытой информации
- `404.html` — страница ошибки
